# nft-mini5

반려동물 등록 정보를 기반으로 SBT와 NFT를 발급하는 학습용 프로젝트입니다.

## 역할 분담

### 백엔드

#### 스마트 컨트랙트 - 김석준
- SBT 컨트랙트 작성
- NFT 컨트랙트 작성
- mint 함수 구현
- transfer 제한
- 보유 조회 함수

#### 지갑 / 세션 - 최규라
- MetaMask 연결
- 현재 계정 관리
- 로그인 상태 유지
- 계정 변경 감지
- SBT 보유 여부 조회
- NFT 보유 여부 조회

#### 서비스 로직 - 이규보
- 반려동물 등록 입력 처리
- SBT 발급 실행
- NFT 발급 실행
- 발급 조건 검사
- 온체인 / 오프체인 데이터 연결
- 조회 결과 기반 기능 제어

### 프론트
- UI 및 사용자 흐름 구성

## 저장소 구조

```text
.
├─ bc/              # 스마트 컨트랙트 영역
├─ be/              # 백엔드 통합 루트
│  └─ logic/        # 서비스 로직 전용 모듈
└─ fe/              # 프론트엔드 영역
```

## 백엔드 서비스 로직 위치

서비스 로직은 `be/logic` 아래에 분리되어 있으며,
지갑/세션 및 스마트 컨트랙트 구현과 겹치지 않도록 포트 기반으로 작성했습니다.

자세한 설명은 아래 문서를 참고하면 됩니다.

- `be/README.md`

## 현재 서비스 로직이 담당하는 기능

- 반려동물 등록
- SBT 발급 요청 및 상태 관리
- NFT 발급 조건 검사 및 발급 요청
- 마이페이지용 보유 상태 조회
- NFT 보유자 전용 UI 게이팅 데이터 제공

## 서비스 로직 실행

```bash
cd be
npm test
npm run check
```
