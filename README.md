# 역할 분담
## 백엔드

### .sol 담당 - 김석준
- SBT 컨트랙트 작성
- NFT 컨트랙트 작성
- mint 함수 구현
- transfer 제한
- 보유 조회 함수

### 지갑 / 세션 담당 - 최규라
- MetaMask 연결
- 현재 계정 관리
- 로그인 상태 유지
- 계정 변경 감지
- SBT 보유 여부 조회
- NFT 보유 여부 조회

### 서비스 로직 담당 - 이규보
- 반려동물 등록 입력 처리
- SBT 발급 실행
- NFT 발급 실행
- 발급 조건 검사 (SBT 있어야 NFT 가능 등)
- 온체인 / 오프체인 데이터 연결
- 조회 결과 기반 기능 제어
